# News Image 2026-11-20

Entry for the make.fun bounty: **Sum up 20 November's world news in one image**

This program generates a PNG image summarizing world news from November 20, 2026.

## Requirements

- Python 3.13
- Standard library only (no dependencies)

## Running

```bash
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output will be at `out/entry.png`.
